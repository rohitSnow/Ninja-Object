# 🥷 Ninja Object

A fast-paced object-destroying mobile game where players must tap flying objects before they hit the ground. Miss them, and it’s game over!

---

## 🎮 Features

- Tap to destroy fast-moving 3D objects
- Random spawn patterns & particle effects
- Smooth difficulty progression
- Firebase integration for score tracking & authentication
- Designed for Android devices

---

## 🛠 Tech Stack

- **Engine**: Unity
- **Language**: C#
- **Backend**: Firebase (Auth + Realtime Database)
- **Platform**: Android
